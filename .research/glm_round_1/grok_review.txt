### Compile-blocker risks (Mac/xcodebuild only)
- **FamilyPod.swift:427** — `let` mutation (above).
- **FamilyPod.swift + LifeContext** — missing members (`threads`, `currentSeasonName`, `activeAmplifierName`, `quests` etc.) → "no member" errors everywhere the builder or other consumers are used.
- **P2PWeaveShare.swift:31** — `LifeEntitySnapshot.attributes: String` but assigned `entity.attributes: [String:String]` (164) and comment claims "JSON bag".
- **LifeContext.swift** — `awardBonusEssence` (532) and possibly others sit after the `extension LifeContext { }` close (530). Scope/declaration errors.
- **LifeContext model surface** is far smaller than SchemaMigrationPlan, CognitiveLoad, DailyBriefings, and FamilyPod expect. Batch of type errors on first `xcodebuild`.
- Missing symbols (Info.plist, targets, AppIntents) noted in handoff are separate; these are pure Swift type issues the Linux harness cannot see.

### @MainActor / actor / Sendable races
- `P2PWeaveShare` statics (`offlineQueue`, `pendingIntegrations` at 45/50) are plain mutable arrays. `queueShare`/`processOfflineQueue` have no actor protection; only `drainPending` and `receiveAndIntegrate` are `@MainActor`.
- `AppLifecycleCoordinator` statics (`lastBackgroundAt`, `bodyThreadLastReadAt`) mutated from `@MainActor` methods only — fragile if any call site escapes.
- `@MainActor` enums (`SacredEchoStore`, `LifeGraphPersistence`, `AppLifecycleCoordinator`, many Integration.*) with static mutable state + direct mutation of `LifeContext` class arrays after `Task.detached` hops (Contacts 159-199). `LifeContext` (class) carries no `Sendable`.
- `GraphInsightGenerator` is `@MainActor struct` with static cache; `invalidateCache()` called from many paths (some async, some inside detached-adjacent flows).
- No `actor` types in the graph for the core mutable state. All relies on "we only call these from main" discipline. Scene phase transitions + async integration paths are the obvious collision surface.

Accurate on knowns (1,3,6,7) and some risks (4,10, partial 2/5). Two clear hallucinations on specifics (#8 location, #9 non-existent cache). Over-generalized the leash-before-permission claim. Several "NEW?" items were already flagged in the handoff docs you required.
